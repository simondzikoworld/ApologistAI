# Bible texts

Catholic Bibles (73-book canon) served to the website's verse lookup and the
mobile app's Bible reader. Generated by `scripts/build-bibles.py`.

| Folder | Language | Translation | Source | Licence |
|---|---|---|---|---|
| `drc` | English | Douay-Rheims, Challoner revision | CrossWire SWORD module `DRC` | Public domain |
| `neocrampon` | French | Sainte Bible néo-Crampon Libre — © 2022 Fraternité de Tibériade | eBible.org (`francl`) | CC BY-SA 4.0 — https://creativecommons.org/licenses/by-sa/4.0/ |
| `platense` | Spanish | Biblia Platense (Straubinger) | CrossWire SWORD module `SpaPlatense` | Public domain |
| `allioli` | German | Allioli-Bibel (1914 edition) | github.com/AlexBocken/allioli | Public domain (Unlicense) |
| `allioli` (1–2 Kings, Ezra, Romans, Hebrews, Zechariah 14) | German | Grünewald-Bibel 1924 (Riessler/Storr) | CrossWire SWORD module `GerGruenewald` | Public domain per CrossWire |
| `wujek` | Polish | Biblia Jakuba Wujka | github.com/poteznytomista/Biblia-Jakuba-Wujka- | Public domain |

Known gaps: German has no Esther 11–16 (Greek additions) or Malachi 4; the
Polish additions to Daniel are incomplete upstream.

The néo-Crampon text is reproduced unmodified apart from conversion to this
JSON layout; it remains under CC BY-SA 4.0.
